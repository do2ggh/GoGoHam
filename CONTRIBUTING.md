# Mitmachen bei GoGoHam

**Deutsch** · [English](#contributing-to-gogoham)

Schön, dass du GoGoHam besser machen willst! Kurz gesagt: **Fehlerberichte und Ideen sind sehr
willkommen – fremden Programmcode nehme ich nicht an.**

## Fehler melden

1. Schau unter **Issues** kurz nach, ob der Fehler schon gemeldet ist. Wenn ja: dort ergänzen
   statt neu anlegen.
2. Erstelle im Programm einen Bericht: *Hilfe → Fehlerbericht erstellen …* → **Kopieren**.
   Er enthält Version, Linux, Python/Qt/Hamlib, Schnittstellen, Funkgeräte-Einstellungen und die
   letzten Meldungen – **aber keine Passwörter und keine QSOs**.
3. Lege unter **Issues → New issue → Fehler melden** einen Bericht an und füge ihn dort ein.
4. Beschreib, **was du gemacht hast, was passiert ist und was du erwartet hättest**. Je genauer,
   desto schneller finde ich den Fehler.

Bitte **ein Fehler je Meldung**. Startet GoGoHam gar nicht, hilft die Ausgabe von `gogoham` im
Terminal und die Datei `~/.local/state/gogoham/gogoham.log`.

**Falsche Contest-Regel?** (Punkte, Multis, Austausch, Termine) – bitte mit Link zur offiziellen
Ausschreibung und der Stelle, die nicht stimmt.

## Ideen und Wünsche

Gern unter **Issues → New issue → Idee oder Wunsch**. Beschreib, was du im Contest erreichen
willst – nicht nur, wie es aussehen soll. Ich kann nicht jeden Wunsch umsetzen und entscheide
selbst, was zu GoGoHam passt. Ein „Nein“ ist nie böse gemeint.

## Warum kein fremder Code?

GoGoHam wird von einer Person entwickelt und gepflegt. Damit das so bleibt – mit klaren Rechten,
einheitlicher Bedienung und einem Programm, für das ich geradestehen kann – schreibe ich den Code
selbst. **Pull Requests werden deshalb automatisch mit einem freundlichen Hinweis geschlossen.**

Hast du schon eine Lösung im Kopf? Dann **beschreib sie in Worten** in einem Issue – ich setze sie
dann selbst um.

Die Lizenz (GPL-3.0 mit Zusatzbedingungen, siehe [ADDITIONAL-TERMS.md](ADDITIONAL-TERMS.md))
erlaubt dir natürlich, eine eigene, veränderte Fassung zu bauen und weiterzugeben – dann aber
**als verändert gekennzeichnet** und mit dem Urhebervermerk.

## Umgangston

Freundlich und sachlich, auf Deutsch oder Englisch. Wir sind alle Funkamateure. 73!

# Contributing to GoGoHam

[Deutsch](#mitmachen-bei-gogoham) · **English**

Thanks for wanting to make GoGoHam better! In short: **bug reports and ideas are very welcome –
I do not accept code from others.**

## Reporting bugs

1. Check the **issues** first to see whether the bug has already been reported. If so, add to it
   instead of opening a new one.
2. Create a report in the program: *Help → Create bug report …* → **Copy**. It contains version,
   Linux, Python/Qt/Hamlib, ports, radio settings and the recent messages – **but no passwords and
   no QSOs**.
3. Open **Issues → New issue → Report a bug** and paste the report.
4. Describe **what you did, what happened and what you expected**. The more precise, the faster
   I can find the bug.

Please **one bug per issue**. If GoGoHam does not start at all, the output of `gogoham` in a
terminal and the file `~/.local/state/gogoham/gogoham.log` help.

**Wrong contest rule?** (points, multipliers, exchange, dates) – please include a link to the
official rules and the part that does not match.

## Ideas and wishes

Welcome under **Issues → New issue → Idea or wish**. Describe what you want to achieve in the
contest – not only how it should look. I cannot implement every wish and decide myself what fits
GoGoHam. A “no” is never meant unkindly.

## Why no code from others?

GoGoHam is developed and maintained by one person. To keep it that way – with clear rights,
consistent operation and a program I can vouch for – I write the code myself. **Pull requests are
therefore closed automatically with a friendly note.**

Already have a solution in mind? Then **describe it in words** in an issue – I will implement it
myself.

The license (GPL-3.0 with additional terms, see [ADDITIONAL-TERMS.md](ADDITIONAL-TERMS.md)) of
course allows you to build and share your own modified version – but **marked as modified** and
with the author attribution.

## Tone

Friendly and to the point, in German or English. We are all radio amateurs. 73!
